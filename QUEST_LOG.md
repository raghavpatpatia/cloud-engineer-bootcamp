# ⚔️ Quest Log

Every quest (lesson) and side quest in **The Combined Bootcamp**, in one place — grouped by world, with XP and direct links. Use it to find the big picture or hunt a specific challenge.

- **⚔️ Quest** — the main lab in each lesson. Building it = **100 XP** (+ **25 XP** quiz).
- **🌟 Side Quest** — optional bonus reps in each world's `exercises.md`. = **50 XP** each.
- **👹 Boss Battle** — the world finale. = **500 XP**.
